## Overview

A production edtech / LMS platform built for two core user flows: **students** learning through self-paced and live courses, and **experts/tutors** who create and manage course content. I own this full-stack, on a small team of 2–3 developers, reporting directly to the engineering lead.

## My Role

- Built and maintained the Angular 15 SSR frontend, including scroll restoration and rendering fixes specific to server-side rendering
- Developed backend REST APIs in Node.js/Express with MongoDB as the data layer
- Managed deployment on AWS EC2, using PM2 for process management and Nginx as a reverse proxy
- Owned production issues end-to-end — from SSR bugs to deployment and Git conflict resolution in a fast-moving small team

## Highlights

- Shipped a full digital products module — listing, detail, and expert views mirroring the existing course layout — with a redesigned certificate generator
- Converted the platform into an Android app using Capacitor, with biometric login, push notifications, and offline handling
- Integrated WhatsApp Business API for OTP authentication and automated messaging flows

## Stack

Angular 15 (SSR) · Node.js · Express · MongoDB · AWS EC2 · PM2 · Nginx
