## Overview

A full-stack analytics dashboard built with React on the frontend and Node.js/Express on the backend, giving business users a live view of key metrics without needing to query the database directly.

## What I Built

- Interactive data visualizations — line/bar trend charts and pie-chart breakdowns — built with a React charting library, wired to live backend aggregation endpoints
- Backend analytics/calculation layer in Node.js/Express, aggregating and transforming raw records into the metrics shown on the dashboard
- Report generation with downloadable exports (PDF/Excel), so users could take a snapshot of any view offline
- Responsive dashboard layout with filterable date ranges and drill-down views per metric

## Stack

React · Node.js · Express · Recharts · MongoDB
