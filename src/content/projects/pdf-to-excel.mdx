## Overview

Built a Windows desktop app that converts PDF tables into clean, ready-to-use Excel files, for a client who needed to process sensitive documents without any data leaving their machine. Everything runs 100% locally: no cloud, no uploads, no accounts.

## What I Built

- Table extraction engine in Python (pdfplumber + pandas) that tries ruled-line detection first, then falls back to text-alignment detection for borderless tables
- Smart cleanup for real-world PDFs: detects the true header row under title banners, repairs digits split by font kerning, and merges tables that continue across page breaks into a single sheet
- Number parsing tuned for financial reports: Indian lakh/crore grouping, currency symbols, percentages, and accounting-style negatives in parentheses
- Batch mode: drop multiple PDFs or point at a whole folder and get one Excel file per PDF, with live per-file progress
- Scanned, image-only PDFs are detected up front and skipped with a clear message instead of failing silently
- Desktop UI written in HTML, Tailwind CSS, and JavaScript, rendered in a native window through pywebview and bridged to the Python engine

## How the Licensing Works

The app is distributed directly to clients, so I designed a license system that needs no server and no internet connection:

- Each license is a cryptographically signed file tied to a small list of approved machines, verified locally on launch
- Editing the file to add a device breaks the signature, and an unlicensed PC never gets past startup
- The trade-off is deliberate: adding a device means issuing a new signed file, but in return the app keeps its "runs entirely offline" promise with no activation step at all

## Packaging and Delivery

- Bundled into a single Windows executable with PyInstaller, with the UI assets and the client's license embedded
- Wrapped in an Inno Setup installer that installs per-user, so employees don't need admin rights, and adds Start Menu and desktop shortcuts plus a proper uninstaller
- Each client gets their own build with their own signed license
