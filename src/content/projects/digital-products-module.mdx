## Overview

Built a complete digital products feature for an LMS platform — a new content type alongside courses — including student-facing listing/detail views and the expert-side management flow.

## What I Built

- Angular UI components for listing, detail, and expert views, matching the existing self-paced course layout for visual consistency
- SSR-specific fixes: scroll restoration and scroll-to-PDF-viewer behavior for server-rendered pages
- Responsive layout fixes across breakpoints using Tailwind CSS
- Backend review flow mirroring the existing course review pattern, reusing established patterns rather than introducing a parallel system

## Certificate Generator Redesign

Rebuilt the completion certificate generator with a new cream/gold visual theme using Google Fonts (Cormorant Garamond, Cinzel, Jost), and fixed a timing bug in `dom-to-image` that was causing certificates to render incompletely on first attempt.

## Stack

Angular · Tailwind CSS · Node.js · Express
